
## 06:53 — Миниапп R2D2 упал (502 Bad Gateway)
- Симптом: скрин Дмитрия — Cloudflare 502, Host Error (gbkz.uk), 06:53 UTC.
- Причина: nginx → /miniapp/ → 127.0.0.1:8080, а python-сервер миниаппа (server.py) умер (запущен вручную nohup, НЕТ systemd-юнита/авторестарта). nginx и гейтвей были живы.
- Фикс: перезапуск `nohup venv/bin/python miniapp/server.py >> miniapp_server.log 2>&1 &` → порт 8080 слушает, /miniapp/ = 200.
- OOM не найден в journalctl; просто умер. Надо завести systemd-юнит для авторестарта (предложено Дмитрию).

## 06:57 — systemd-юнит для миниаппа (по «да» Дмитрия)
- Создан `~/.config/systemd/user/miniapp.service` (копия в services/miniapp.service): python server.py на :8080, Restart=always, RestartSec=5, лог append в miniapp_server.log, enabled.
- Работает: active (running), порт 8080 слушает, /miniapp/ → 200 локально и публично.
- Больше не умрёт молча: автоподъём при падении и при ребуте (linger=yes).

## 07:01 — Календарь в миниаппе не работал (500)
- Симптом: /api/calendar → {"error": "No module named 'google'"} 500.
- Причина: миниапп поднят через venv/bin/python, а google-библиотек в venv НЕ было (system python3 их имел — раньше сервер, видимо, запускался системным python).
- Фикс: `venv/bin/pip install google-api-python-client google-auth google-auth-oauthlib google-auth-httplib2`, restart miniapp.service.
- Проверено: /api/calendar → 200, события отдаются (сегодня «Дегустация вина» 18:00).
