## 🔍 ИИ-ревью кода мини-аппа (16:25–16:30) — замечания и фиксы
Дмитрий скормил код какому-то ИИ-ревьюеру; тот выдал список критических замечаний. **ВСЕ ИСПРАВЛЕНЫ**:

### Безопасность (auth.py, server.py)
1. **Пароли sha256 → PBKDF2**: `hashlib.pbkdf2_hmac('sha256', pw, salt, 100_000)`, соль 16 байт (secrets.token_hex(16)), формат `salt$iter$hash`, **мин. длина 4→8**. Миграция: старые хэши (`salt$sha256`) при успешном входе пересохраняются в PBKDF2 (check_password → перехеширует).
2. **Утечка initData**: убрана запись в `/tmp/miniapp_initdata_<ts>.txt` и `_last.txt` (сырые токены/подписи не должны лежать на диске). В логе осталась только длина.
3. **SQLite**: `_conn()` теперь `sqlite3.connect(DB, timeout=15)` + `PRAGMA journal_mode=WAL` при init_db.
4. **Парсер .env**: `load_bot_token()` → regex `^TELEGRAM_BOT_TOKEN\s*=\s*["']?([^"'\s]+)` вместо построчного startswith.
5. **Захардкоженные данные → env**: OWNER_TG_ID (MINIAPP_OWNER_TG_ID), пути DB/static/sources (MINIAPP_*), GCAL_DIR/CAL_ID (MINIAPP_GCAL_DIR/MINIAPP_CAL_ID), MYMEMORY_EMAIL, OPENCLAW_CALENDAR_DIR — всё через os.getenv с дефолтами.

### Архитектура (server.py)
6. **Блокирующий I/O под CACHE_LOCK** → **фоновый воркер** (`start_cache_worker`): поток обновляет DIGEST_CACHE и CAL_CACHE в фоне (каждые 60с), `/api/digest` и `/api/calendar` отдают тёплый кеш за 1–2мс (stale-while-revalidate). Первый запрос при пустом кеше — синхронная сборка.
7. **Префикс /miniapp**: фронт зовёт `/miniapp/api/...`, сервер проверял `/api/...` (nginx делает rewrite). Добавлена `_norm_path()` — сервер сам снимает префикс `/miniapp`, работает и без nginx.

### Производительность фронта (index.html) — минус ~2.5МБ
8. **Babel standalone УБРАН** (главный убийца TTI): JSX **прекомпилирован заранее** через Babel CLI → `static/vendor/app.compiled.js` (94KB, 399×React.createElement, classic runtime, БЕЗ jsx-runtime). `<script type="text/babel">` → обычный `<script src>`. ⚠️ **УРОК**: Babel 8 (npm latest) генерирует automatic runtime (jsxDEV → import jsx-runtime, не работает в браузере) — ставить **Babel 7** (`@babel/core@7 @babel/cli@7 @babel/preset-react@7`) + конфиг `{presets: [["@babel/preset-react", {runtime: "classic"}]]}`. babel.config.cjs НЕ подхватывается CLI из другой директории — использовать `--config-file` с абсолютным путём.
9. **CDN → локальные vendor** (`static/vendor/`): react.production.min.js, react-dom.production.min.js (unpkg), phosphor-icons css+woff2 (jsdelivr), tailwind.css (сгенерирован Tailwind CLI по используемым классам, 14.6KB). Остался только telegram-web-app.js (обязателен).
10. **Tailwind CDN** (рантайм-скан DOM) → статический CSS: `npx tailwindcss -i ... -o static/vendor/tailwind.css --content index.html app.compiled.js`. ⚠️ классы пишутся в JSX → после компиляции они в app.compiled.js, поэтому content должен включать ОБА файла.
11. **Google Fonts/Inter убраны** → системный стек `-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", Roboto, sans-serif` (0 сетевых запросов, выглядит нативно).
12. **Leaflet удалён** (мёртвый код, карта не использовалась) — минус ~150KB и лишний CSS.
13. **`/api/bootstrap`** — единый эндпоинт инициализации: отдаёт `{user, sources, calendar, digest, curs}` одним запросом (вместо цепочки auth/me → sources → calendar → digest). Фронт: один fetch при старте.
