# R2D2 Mini App UI Refinement Pack

Этот пакет подготовлен для агента, который будет дорабатывать `prototype-v12.html` без изменения структуры экрана.

Состав:
- `SYSTEM_PROMPT.md` — системный промпт для агента.
- `DESIGN_SPEC.md` — размеры, отступы, иконки, токены, правила блоков.
- `COLOR_PALETTES.md` — светлая и тёмная палитры с рекомендациями.
- `ICON_MAP.json` — карта иконок Lucide по сервисам.
- `UI_CHECKLIST.md` — checklist для финальной вёрстки.

Главный принцип: структура экрана сохраняется, меняется только visual layer.
